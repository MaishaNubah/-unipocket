# UniPocket 🏦

> "Where did all the money go? Food and rent and rides in tow."

**UniPocket** is a sleek, responsive client-side web application designed for university students to track budget inflows, monitor daily expenditures, and view structural saving habits instantly.

---

## ✨ Application Architecture & Features

* **🎛️ Dashboard Grid:** Dynamically updates live cards for *Total Budget / Income*, *Grand Total Spent*, and *Grand Total Balance*.
* **💰 Log Budget Input:** Handles incoming streams of funds (Allowances, Part-time salaries, or Stipends).
* **💸 Log Student Expenses:** Dynamically categorizes outlays into *Food*, *Rent*, *Rides (Fare)*, and *Other Essentials*.
* **📋 Clean Student Balance Sheet:** Generates an interactive, chronological live ledger tracking user cash flow with individual item deletion control.
* **💡 Where to Cut & Spare:** An automated student wallet guide that calculates threshold rules in real time to display warning notifications or positive budget feedback.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic document structure modeling.
* **CSS3 Custom Variables:** Smooth visual properties utilizing the modern `Plus Jakarta Sans` typography layout and mobile-responsive grid flex patterns.
* **Vanilla JavaScript (ES6+):** Pure functional programming models for mathematical loops, state array adjustments, and immediate DOM insertion without framework overhead.

---

## 🚀 Execution Guide

1. Double-click **`manger.html`** inside this project directory to run the fully functional system locally inside any modern browser.
2. The ledger initializes with realistic default student entry models for interactive demonstration purposes.SS
